## 2. 判断依据

- **真实数据**：用户电脑上 0.2.0 时的状态：Claude 干了 8 轮、生成 166 张卡、待审 80 张、审过 0 张。逐个文件审在长会话里没人坚持得下来。所以审阅改成**按轮**：每一轮一个标题（用户自己说的话），看完一轮心里有数，`Y` 一键整轮通过。
- **诚实**：整轮通过时，只有真正在屏幕上停留够久的文件才算审过。计时从“第一次出现”改成“累计显示时长”，翻一遍再回来等着的作弊方式也不算。
- **留存不能靠挂机奖励**（创立会话里竞品的通病）：连续天数只认有用的一天（审过文件、刷够卡、解出每日谜题），只玩游戏不算；任务和成就只给 ⚡ 不给 💰（💰 只看 Claude 的成果）。
- **不想让人自己从头写一个**：第一次打开按 Enter 就接入；`cowait split` 认识六种终端；独立可执行文件不需要 Node；`cowait update` 告诉你怎么升级；进度、成就、连续天数、每周回顾都只在 Cowait 里。
- **付费不伤免费版**：审阅、留言、三个游戏、学习、进度全部免费；Pro 是“更多”（不限练习、加班模式、可分享的报告）。没配置 Polar 时 Pro 功能对所有人开放，避免出现“能看不能用”的半成品体验。

## 3. 做了什么

**界面**（我自己做）
- 按轮审阅：标题、用时、测试结果、文件条（`●✓✎·–`）、`Y` 整轮通过、`[ ]` 换轮、完成提醒按 Enter 直达、24 小时归档、旧卡片自动按轮迁移。
- 面板外壳：顶栏加 🔥 连续天数（今天没打卡时变灰）；四个页面（加了「我」）；底栏只有一行当前页面的按键；反馈提示先、奖励提示后。
- 欢迎页（Enter 接入当前项目、`g` 全局、`L` 切换语言）、周回顾、「我」页（等级、连续、任务、成就、设置、Pro）。
- 游戏列表 + 栈机谜题和代码速打的界面；捉虫地牢加了 Esc 回列表和 Pro 的加班模式。
- 进度系统（`engine/progress.ts`）、审阅报告（`report.ts`）、`activate/license/deactivate/upgrade/report` 命令、每天一次的更新检查。
- README 中英文重写、官网 `site/index.html`、配图重录（GIF 演示新流程，截图加了「我」页）。

**并行交给 4 个后台 agent**（各在独立的 git worktree 里，只碰指定文件，做完我再合并）
- 栈机谜题引擎（`game/stack.ts`，20 个测试）：它主动改了一处计星规则：用了提示最多两星，避免“用提示反而星更多”。
- 代码速打引擎（`game/sprint.ts`，23 个测试）：粘贴不算纪录（>250 WPM）、停顿最多算 3 秒。
- 许可证（`license.ts`、`product.ts`、`open.ts`，26 个测试）：查了 Polar 源码里的错误文案来区分“设备数满了/已过期/已停用”；Windows 打开网址用 rundll32 避免 `&` 被 cmd 当成命令。
- 打包分发（`runtime.ts`、`update.ts`、`compile.mjs`、安装脚本、CI、release workflow，29 个测试）：发现并修了“cli 包里的 hook 代码会在每条命令时自己跑一次”的隐患；在用户电脑上实测 Windows 独立可执行文件（隐藏的真实控制台里跑面板、注入按键）。

## 4. 打磨中发现并修掉的

- 奖励提示（成就）抢在操作反馈（`✓ +1⚡`）前面显示 → 奖励延后一个 tick 入队。
- 帮助页在 60×26 里被截掉最后一节 → 文案精简到能放下。
- 写留言时“Enter 发送 · Esc 取消”出现两遍 → 去掉审阅页自己那一行。
- Claude 还在干活时空状态写“上一轮” → 改成“这一轮还在进行”。
- 整轮通过的提示“看过的 0 个 +0⚡”很别扭 → 按全看过/部分看过/都没看三种说法。
- 速打在没有颜色的终端里看不出错在哪 → 目标行下面另起一行显示你打的字。
- 栈机谜题看不出栈顶在哪边 → 加“← 右边是栈顶”；难度标记和结果星级区分开（“难度 3/3”）。
- 游戏列表战绩没有数据时显示“最快 — WPM” → 没有的项不显示。
- 首次 settle 会把老用户已满足的成就一次性刷屏 → 静默发放；`normalizeState` 的 undefined 覆盖默认值导致这一条失效，一并修了。
- 录图：成就提示意外混进截图、假终端合并连续按键导致没切到「我」页、无头 Chrome 偶尔不出图 → 都修了。

## 7. 决定开源，不做付费

做完之后用户问：“你个人觉得这个项目值得别人开会员吗，开源比较好还是做成产品挣钱？”

我的判断（原样记录，供以后参考）：
- 个人会员很难挣到钱：开发者很少为“打发等待时间”付费，竞品基本都免费开源；Pro 的内容（不限练习、加班模式、报告）属于可有可无；核心技术门槛低，几天就能抄个大概；本地的许可证检查很容易绕过；Anthropic 随时可能自带类似功能。粗算 1000 个活跃用户、2–3% 付费、每月 4 美元，每月约 100 美元。
- 开源更好：一个要挂进别人 Claude Code、读他们代码改动的工具，开源才让人放心装；GitHub 和 Claude Code 社区是这类工具唯一便宜的获客渠道；一个真有人用的开源项目，对用户个人（实习、求职）的价值可能更大。
- 真正可能有人付钱的是团队（“AI 写的代码有没有人真的看过”），但需要服务器端、管理后台，而且需求没验证过。建议先开源、观察留存、找团队负责人聊，有明确付费意愿再做闭源的团队版。
