等 Claude 的时候，看看它在写什么

While Claude works, read what it writes

Cowait 是放在 Claude Code 旁边的小面板。每一轮改了哪些文件一目了然，有问题写一句话，Claude 下一步就看到，不用打断它。看完了，玩一局、解一道每日谜题，或者刷几张卡。

Cowait is a small panel next to Claude Code. Every turn's files at a glance, and one line from you reaches Claude on its next step, no interruption. Done reading? Play a round, solve the daily puzzle or study a few cards.

npm install -g cowait-cli

需要 Node.js 20 或更新版本。Needs Node.js 20 or newer.

然后在项目里运行Then, in your project, run cowait split，按一下 Enter 就接入好了。 and press Enter once to hook it up.

四个页面Four tabs

按轮看 Claude 改了什么

See what Claude changed, turn by turn

每一轮一组：你当时说的话、用时、测试结果，下面是这一轮改过的文件。同一个文件改了几次就合在一起看。只有在屏幕上停留够久的改动才算审过，所以覆盖率这个数是可信的。

One group per turn: what you asked, how long it took, whether tests passed, then its files. Several edits to one file are read together. Only changes that stayed on screen long enough count as reviewed, so the coverage number means something.

三个为等待设计的游戏

Three games built for waiting

捉虫地牢：回合制卡牌闯关，海森堡虫、内存泄漏团、栈溢出。栈机谜题：每天一道，所有人同一题，解完能分享。代码速打：照着打 Claude 刚写的代码。

Debug Dungeon: a turn-based card roguelike against Heisenbugs and memory leaks. Stack Puzzle: one a day, the same for everyone, made to share. Code Sprint: type the code Claude just wrote.

一个键一步，随时能停。开游戏的能量，靠认真审代码来赚。

One key per step, stop any time. The energy to play is earned by actually reviewing.

Understand what Claude just wrote

Spaced-repetition flashcards: five built-in decks on Git, networking, concurrency, LLMs and system design, AI decks on any topic, or a quiz on the code Claude just changed.

Level, streak, today's quests

常见问题Questions

会不会拖慢 Claude？Does it slow Claude down?

不会。hook 是一个没有依赖的小程序，每次几十毫秒，永远以 0 退出，带 4 秒硬超时。它不挂在工具调用之前（PreToolUse），只在之后记一笔。

No. The hook is a tiny dependency-free program that takes a few tens of milliseconds, always exits 0 and has a hard 4-second timeout. It never runs before a tool call (no PreToolUse), only after.

我的代码会被发到哪里吗？Does my code go anywhere?

不会。改动只存在你自己电脑上。会联网的只有两件事：每天最多一次查有没有新版本，以及你主动让 AI 出题时把主题或几处 diff 发给模型。都可以关掉。没有账号、没有统计、没有遥测。

No. Diffs stay on your machine. The only network calls: at most one version check a day, and the topic or a few diffs when you ask the AI for a deck. Both optional. No account, no analytics, no telemetry.

支持哪些终端和系统？Which terminals and systems?

Windows、macOS、Linux。cowait split 能在 Windows Terminal、tmux、zellij、WezTerm、kitty、iTerm2 里自动分屏；别的终端自己开一个窗格运行 cowait 就行。

Windows, macOS and Linux. cowait split opens the pane for you in Windows Terminal, tmux, zellij, WezTerm, kitty and iTerm2; elsewhere, open a pane and run cowait.

怎么卸载？How do I uninstall it?

cowait uninstall 只删 Cowait 自己加的 hooks，其他配置原样保留；安装时也会先备份 settings.json。

cowait uninstall removes only the hooks Cowait added and leaves everything else alone; installing backs up settings.json first, too.
